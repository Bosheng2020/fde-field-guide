## 3. Go / No-Go 门槛

### 成果与产品

- [ ] 指定用户已在真实工作流中完成有代表性的任务。
- [ ] 成功指标、基线、目标和测量负责人已达成一致。
- [ ] 用户能够清楚看到不支持的用途和产品局限。
- [ ] 用户反馈、纠正和升级路径已端到端验证。
- [ ] 已检查无障碍要求与关键用户路径。

### 评估与安全

- [ ] 固定版本已通过评估计划和回归测试集。
- [ ] 不可接受的失败为零，或已获得明确的例外批准。
- [ ] 已评估工具调用、权限、证据使用和审批边界。
- [ ] 红队与滥用测试覆盖本次部署的真实威胁模型。
- [ ] 生产抽样能够发现漂移，并将失败转成评估案例。

### 安全、隐私与治理

- [ ] 已测试身份、角色、租户和最小权限控制。
- [ ] 数据分级、同意、驻留、保留、删除及供应商条款均已批准。
- [ ] 密钥与敏感内容不会进入不安全的日志和提示词，或已脱敏。
- [ ] 审计记录可识别用户、版本、证据、审批和副作用。
- [ ] 所需的法务、安全、隐私、风险与合规负责人已批准所述范围。

### 可靠性与成本

- [ ] 已测试负载、超时、重试、幂等、部分失败和依赖中断行为。
- [ ] 已配置 SLO、错误预算、限流和成本预算。
- [ ] 降级方案能够向用户传达安全且清晰的系统状态。
- [ ] 实际负责操作的人员已演练回滚和紧急停用。
- [ ] 容量和供应商配额能够以足够余量支持放量计划。

### 运维与支持

- [ ] 仪表盘和告警覆盖质量、安全、可靠性、延迟、成本和采用情况。
- [ ] 每个告警都有负责人、严重等级、运行手册和经过测试的通知路径。
- [ ] 已明确值班、客户沟通、事故指挥和升级责任。
- [ ] 可追溯模型、提示词、政策、检索索引、工具和应用版本。
- [ ] 发布后复盘和决策节奏已加入相关人员日历。

### 采用与变革管理

- [ ] 用户知道何时可以信任、何时需要核查、纠正、覆盖或升级。
- [ ] 管理者理解工作流和职责将如何变化。
- [ ] 推广对象包含内部倡导者，也包含抵触或高风险用户群。
- [ ] 培训使用真实案例并说明局限，而不仅是理想路径演示。
- [ ] FDE 团队退出后，仍有明确的业务与技术运营负责人。
